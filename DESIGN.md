# Brilina Dev — Design Direction

## Brand
BRILINA DEV
Spec-Driven Developer & AI-Assisted Product Builder
THINK → SPECIFY → BUILD → VERIFY

Preserve the existing Brilina Dev logo.

## Visual
Premium, technical, precise, minimal, modern, structured, product-oriented. Dark-first. Use logo-derived blue/red/black/navy/white without excessive color.

## Avoid
Generic AI robots, brain imagery, excessive 3D, particle backgrounds, excessive neon/gradients, unnecessary glassmorphism, decoration without purpose.

## Typography
Modern readable type system with strong hierarchy.

## Animation
Use Motion for intentional page/section transitions, reveals, hover/focus states, project cards, navigation, and subtle image interactions. Respect prefers-reduced-motion.

## Public project UI
Cards should communicate project name, concise description, category/status when useful, selected technologies, visual preview, and clear action.

Detail pages may contain hero, overview, problem/objective, approach, architecture, features, gallery, verification/current state, technologies, links. Empty optional sections must not render.

## Responsive/accessibility
Mobile-first quality across mobile/tablet/desktop. Use semantic HTML, keyboard navigation, visible focus, adequate contrast, alt text, reduced-motion support, labels, and accessible errors.
