# Brilina Dev

Planning repository for the Brilina Dev professional portfolio.

Core philosophy: THINK → SPECIFY → BUILD → VERIFY

This project uses React + TypeScript + Vite, Bootstrap, Motion, Cloudflare Workers, D1, KV where appropriate, ImageKit for media, and Resend for email.
